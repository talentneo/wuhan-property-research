Property research with evidence you can inspect.

A local-first research skill that turns Wuhan housing information into a decision-oriented card: official project identity, one-home-one-price evidence, planning constraints, schools, transport, layouts, adverse factors, and verification questions.

Decision card

Room-level evidence

The query script resolves public project, building, room, and one-home-one-price records, then emits JSON, CSV, and interactive HTML for local analysis.
